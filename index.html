STEP 5

Controls, fitness, and statistics

Choose the metric and grouping level. Comparisons use control-aware normalization and report effect sizes with multiple-testing correction.

Relative fitness / phenotype

Statistical comparisons
Welch two-sample t tests are used for the default control comparisons because equal variance is not assumed. Hedges’ g reports standardized effect size. Benjamini–Hochberg adjustment is applied across displayed tests. These defaults are descriptive and should be matched to the experimental unit and design.
